# Typora — Typing Speed Challenge ⌨️

Typora is a responsive typing speed game where players can practice solo, race against a bot, or compete with another player in real-time multiplayer rooms.

## Features
- Solo typing practice
- Bot racing mode
- Real-time multiplayer with room codes
- Three difficulty levels
- Typing speed (WPM) and accuracy tracking
- Global leaderboard
- Personal best records

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Socket.IO
- Firebase Firestore
